Overview

two-hit integrates somatic mutation data (MAF format) with copy number segment data (SEG format) to identify biallelic inactivation events in tumor suppressor genes and mutation-with-amplification events in oncogenes. Gene roles (oncogene / TSG / both) are derived from the OncoKB cancer gene list.

Truncating Mutation Types

By default: Nonsense_Mutation, Frame_Shift_Del, Frame_Shift_Ins, Splice_Site, Translation_Start_Site. Splice_Region can optionally be included.

Input Formats

MAF: Standard AACR GENIE MAF format (tab-separated). Required columns: Hugo_Symbol, Chromosome, Start_Position, End_Position, Variant_Classification, HGVSp_Short, Tumor_Sample_Barcode. Optional: t_alt_count, t_ref_count for VAF.

SEG: Standard CBS-style segment format (tab-separated). Required columns: ID, chrom, loc.start, loc.end, seg.mean. Column name matching is case-insensitive.
